# Детекция ботов-парсеров Авито

Решение тестового задания: по событиям куки за сутки предсказать, насколько вероятно, что это трафик сервиса автоматического сбора данных. Метрика — Precision при Recall ≥ 0.7.

Всё решение в [`solution.ipynb`](solution.ipynb): EDA, очистка событий, признаки, валидация, сравнение моделей, финальная модель и `submission.csv`. Краткое описание подхода — в первой ячейке ноутбука.

## Запуск

```
├── solution.ipynb
├── metric.py          # официальная метрика из задания
├── requirements.txt
└── data/              # данные задания (в репозиторий не кладу)
    ├── train.csv
    ├── test.csv
    └── events.csv.gz
```

```bash
pip install -r requirements.txt
```

Дальше запустить все ячейки ноутбука (Restart & Run All), в конце появится `submission.csv`. Python 3.11, random seed зафиксирован. Долгие эксперименты (сетка параметров, абляции) включены флагом `RUN_LONG` в первой ячейке с кодом.

## Результат

| валидация | P@R≥0.7 |
|---|---|
| по времени (5 фолдов по 2 дня) | 0.775 ± 0.035 |
| RepeatedStratifiedKFold 5×3 | 0.823 ± 0.044 |

Модель: среднее рангов LightGBM (3 сида) и CatBoost на 133 признаках, посчитанных по событиям окна.
